# GitHub Copilot Instructions for peanutbook-docs

## This repo is the public documentation source of truth

This is the **public** docs repo (GitHub + Read the Docs / `peanutbook.com`). Edit Markdown under `docs/` and `mkdocs.yml` **directly here**.

The private development repo `~/peanutbook` also contains a `docs/` folder, but it is **private/internal notes only** — never published, and not a source to sync from. Its `docs/sync-public-docs.sh` script is retired: a past run overwrote this repo with the private copy's stale content via `rsync --delete`, deleting the homepage logo, several public-only doc pages, and preview images. Do not run it, and do not treat `~/peanutbook/docs` as authoritative for anything published here.

## Project structure
- `docs/` — all published Markdown pages, referenced from `mkdocs.yml`'s `nav`
- `docs/img/` — images referenced by pages
- `mkdocs.yml` — site config and navigation
- `build-site.sh` — builds with `--strict` and deploys (`deploy`/`rtd`/`both` targets)
- No Python source belongs in this repo

## Before considering a docs change done
Run `bash build-site.sh` (or `mkdocs build --strict -f mkdocs.yml`). `mkdocs.yml` sets `strict: false`, but `build-site.sh` overrides with `--strict`, so a broken link or missing image reference will fail the real build even though a plain `mkdocs build` wouldn't catch it.

## Adding a new page
1. Create the Markdown file under `docs/`.
2. Add it to `nav:` in `mkdocs.yml`.
3. Run the strict build to confirm no broken links.
